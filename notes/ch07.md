# ch7 - scope, duration and linkage

### 7.1 - compound statements (blocks)
- - -
- a **compound** statement (also called a **block**) is a group of zero or more statements that are treated by the compiler as if it were a single statement
- blocks begin with a `{` and end with `}`
- functions can't be nested inside other functions, but blocks can be nested inside other blocks where the enclosing block is called the **outer block** and the enclosed block is called **inner/nested block**
- the **nesting level** of a function is the maximum number of nested blocks you can be inside at any point in the function, the maximum number of levels supported for now is 256
