# compound types: references and pointers

### 12.1 - introduction to compound data types
- - -
- **compound data types** (also called composite data types) are types that are defined in terms of other existing data types
- c++ supports the following compound data types: 
    1. functions
    2. c-style arrays
    3. pointers (to objects and functions)
    4. pointers (to member types)
    5. reference types (l-value and r-value)
    6. enumerated types
    7. class types (structs, classes, unions)
- we have already been using one compound type regularly, i.e functions
- if we take a function `void doSomething(int x, double y)` for example, it is composed of several fundamental types 

### 12.2 - value categories (lvalues and rvalues)
- - -
- in the earlier chapters, we learnt that expressions evaluate to a singular value and they sometimes have side effects too, but besides producing values and side effects, expressions can do one more thing, they can evaluate to objects or functions 
- to determine how expressions should evaluate and where they can be used, all expressions have two properties: a type and a value category
- **the type of an expression**: this is equivalent to the type of the value, object or function from the evaluated function, for example: `12/4 -> int/int = int`, so whatever value is produced from said expression, becomes the type of the expression
- **the value category of an expression**: this indicates whether an expression resolves to a value, a function or an object of some kind
